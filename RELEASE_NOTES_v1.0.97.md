### 🧹 Versión 1.0.97 — Eliminación del Botón Flotante Redundante (Limpieza Total de UI)

Esta versión completa la transición al nuevo paradigma nativo de Model Context Protocol (MCP) eliminando el botón flotante antiguo:

#### 🗑️ Limpieza de Interfaz:
- **Eliminación del Botón Flotante Antiguo (`fabAgentMode`)**:
  - Se eliminó el botón verde flotante que aparecía sobre la barra de chat.
  - La pantalla principal queda 100% despejada, limpia y sin elementos flotantes invasivos.
  - Todo el control móvil autónomo ahora se gestiona de forma nativa desde el chat mediante el servidor MCP `MobileUseMcpServer` y el interruptor en Servidores MCP.
