### 📱 Versión 1.0.96 — Accesos Rápidos para Activar Servidores MCP y Mobile Use

Esta versión facilita el acceso inmediato para activar/desactivar el servidor MCP de Mobile Use desde cualquier parte de la aplicación:

#### 🎯 Puntos de Acceso para Activar:
1. **Botón '+' en el Chat**: Nuevo acceso directo '🔌 Servidores MCP (Mobile Use, Memoria...)' al tocar el botón '+' junto a la barra de mensaje.
2. **Ajustes de la App**: Botón verde destacado '🔌 Servidores MCP (Control Móvil, Memoria…)' dentro del diálogo de Ajustes de conexión.
3. **Comando Slash**: Escribiendo `/mcp` en la barra de texto del chat.
4. **Modo Codex PC**: Tocando la barra superior de contexto para acceder al Administrador MCP.
5. **Interruptor Nativo**: En la lista de servidores, simplemente activa el switch de 'Mobile Use (Control de Pantalla y Gestos)' para pre-armar el servicio.
